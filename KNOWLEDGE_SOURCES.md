# Bundled knowledge documents

These three PDFs were supplied through the user's connected Drive and copied into the knowledge base for later indexing. They are source material for grounded reports, not validation of NeuroMind's classifier.

| Folder | Document |
| --- | --- |

The server's Admin RAG endpoint reads this directory when `KNOWLEDGE_BASE_PATH` resolves here. Source text extraction was tested; database and semantic indexing await a configured environment. Review content and redistribution rights before public deployment.
