# Binary model training and integration

Use `colab/Phase1_Final_Models.ipynb` on an authorized GPU environment and run its cells from this updated ZIP. Adjust `PROJECT_ROOT` and the Drive file paths first. The notebook has **not** been rerun in this ZIP. The training scripts accept exactly `Non-Dementia` and `Dementia` and reject unaligned modality labels or missing features.

1. `python -m training.prepare_speech_embeddings --audio-root <real_speech_folder> --output-dir <sequence_dir> --label-map training/speech_label_map.example.json --resume` produces Wav2Vec2 sequences and the matching saved backbone.
2. `python -m training.train_speech --manifest <sequence_dir>/speech_sequence_manifest.csv --output-dir <speech_output>` exports `neuromind_speech_bilstm_attention.pt`, its manifest, held-out metrics and `speech_patient_embeddings.csv` (128 speech features). Confirm patient-level split quality and dementia recall.
3. Join genuine memory, attention and lifestyle rows for **the same patients** with `python -m training.build_fusion_dataset --speech <speech_output>/speech_patient_embeddings.csv --memory <memory.csv> --attention <attention.csv> --lifestyle <lifestyle.csv> --output <aligned.csv> --label-map training/fusion_label_map.example.json`. Inspect the real label encoding before choosing this example map. The 15 tabular fields must use the website's score definitions and units. Never treat the older synthetic fusion rows as clinical evidence.
4. `python -m training.train_fusion --dataset <aligned.csv> --speech-artifact <speech_output>/neuromind_speech_bilstm_attention.pt --output-dir <fusion_output>` exports `neuromind_multimodal_transformer_binary.pt`, its exact feature manifest, held-out metrics, patient predictions and seven binary ablations. A missing real modality stops this step.
5. `python -m training.validate_phase1_artifacts --speech-artifact <speech_output>/neuromind_speech_bilstm_attention.pt --fusion-artifact <fusion_output>/neuromind_multimodal_transformer_binary.pt` checks binary outputs and matching speech dimensions. `python -m training.install_phase1_artifacts --speech-artifact <speech_output>/neuromind_speech_bilstm_attention.pt --fusion-artifact <fusion_output>/neuromind_multimodal_transformer_binary.pt --wav2vec-backbone <sequence_dir>/wav2vec2_backbone --project-root . --update-env` installs only validated artifacts.
6. Set up backend AI dependencies, then run `npm run models:status`, `npm run test:backend` and a real held-out assessment. Check the two probabilities, SHAP, indexed citations, report advice, PDF download and sharing.

The included `source_checkpoints/best_simple_bilstm_model.pth` is a legacy baseline, not the trained attention model and not usable directly by the server. An experimental exporter is provided at `training/export_legacy_simple_speech.py` for a matching 768-dimensional Wav2Vec2 backbone; if used, re-extract that model's **256**-dimensional patient speech embeddings and train fusion from scratch. Its reported earlier patient accuracy was only about 52.6%, and it is not suitable for clinical claims.
